Roster Final Description

URL: All Elite Wrestling Roster

Instructions: Scroll down past the 'Champions' section, and pick a thumbnail image of a wrestler from the page, then hover over it with your cursor.

Triggers

  • Thumbnail
    • Hover on
    • Hover off
    • Click on
    • Click off
  • Next button
    • Hover on
    • Hover off
    • Click on
  • Previous button
    • Hover on
    • Hover off
    • Click on

Rules

  • Thumbnail
    • Hover on
      • Thumbnail zooms in by 10%
    • Hover off
      • Thumbnail zooms out by 10%
    • Click on
      • Entire card flips to back side
      • Text with facts about the wrestler appears
      • Next and previous buttons appear
    • Click off
      • Entire card flips to front side
      • Text with facts about the wrestler disappears
      • Next and previous buttons disappear
  • Next button
    • Hover on
      • Cursor changes to finger
    • Hover off
      • Cursor changes back to pointer
    • Click on
      • Text box slides to the left to reveal next sequential text box
  • Previous button
    • Hover on
      • Cursor changes to finger
    • Hover off
      • Cursor changes back to pointer
    • Click on
      • Text box slides to the right to reveal next sequential text box
